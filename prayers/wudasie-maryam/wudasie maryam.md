# Wudasie Maryam - Daily Checklist (am, geez, en)

This file tracks the `wudasie-maryam` prayer data by language and day.
Each day file should follow the same schema:
- `title`: string
- `content`: object where keys are verse numbers (`"1"`, `"2"`, ...) and values are verse text

## Quick Notes About The Data
- Naming convention should stay consistent: `NN-dayname.json`.
- Keep day order fixed from Monday (`01`) to Sunday (`07`) for all languages.
- Validate each file has a non-empty `title` and a valid `content` object.
- Verse keys should be sorted numerically when rendering.
